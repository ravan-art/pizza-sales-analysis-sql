# 🍕 Pizza Sales Analysis | SQL

## 📌 Project Overview

This project analyzes pizza sales transaction data using **SQL** to evaluate sales performance, customer ordering patterns, product performance, and time-based sales trends.

The project focuses on calculating key business KPIs and answering practical business questions using SQL.

---

## 🎯 Business Objectives

The main objectives of this project were to:

* Analyze overall pizza sales performance
* Calculate key business KPIs
* Analyze daily and hourly order trends
* Identify top-selling pizzas
* Analyze pizza category performance
* Understand customer ordering patterns
* Identify sales trends and business opportunities

---

## 🛠️ Tools & Technologies

* SQL

* Aggregate Functions

* JOINs
* COUNT(DISTINCT)
* Date Functions
* Subqueries
* KPI Analysis

## 📊 Key KPIs

The following KPIs were calculated:

* Total Revenue
* Average Order Value
* Total Pizzas Sold
* Total Orders
* Average Pizzas per Order

---

## ❓ Business Questions

The analysis answers questions such as:

1. What is the total revenue generated?
2. How many orders were placed?
3. How many pizzas were sold?
4. What is the average order value?
5. What are the daily order trends?
6. What are the peak ordering hours?
7. Which pizza categories perform best?
8. Which pizzas are the top sellers?
9. Which products generate the highest revenue?
10. What sales patterns can help business planning?
